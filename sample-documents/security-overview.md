# Security Overview

## Data protection

Customer data is encrypted at rest using AES-256 and in transit using TLS 1.2 or later. Encryption keys are maintained in a managed key service with restricted administrative access.

## Access management

Administrative access requires multi-factor authentication. Privileged access is reviewed quarterly and removed when no longer required.

## Business continuity

The service maintains daily encrypted backups and conducts an annual recovery exercise. Recovery objectives are documented internally and provided during due diligence under appropriate confidentiality controls.
